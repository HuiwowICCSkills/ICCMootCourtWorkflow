# 正文与修改

## 按产品控制输出

| 用户要的产品 | 交付重点 |
|---|---|
| 写作思路/逐段指南 | 按实际正文顺序说明每段任务、规则、事实、推理桥梁、必要反论及转接；创新点放在对应位置；在思路说明中提醒论证局限与待补证处 |
| 空白结构 | 依已有争点设置层级标题及空白 I/R/A/C 槽位；不填论证、示范结论、引证或长篇使用说明 |
| 连续书状 | 用论证性标题和自然段连续推进；IRAC 是逻辑骨架，不必把 I/R/A/C 标签印在提交稿上 |
| 逐问作答 | 保留问题对应关系，各问处理自己的条件、结论和适当请求，不擅自合并成连续书状 |
| 仅正文 | 只做用户或规则指定的实体论证/请求部分，不擅加封面、目录、事实陈述等全套前置页 |
| 完整 memorial | 根据当届规范配置必要部分，并检查事实陈述、概要、正文、法源表和请求的一致性 |
| 局部修改 | 只动指定范围及完成该修改必需的依赖；保留其余结构、事实状态和用户删改 |

标题和槽位数量取决于本题，不复制过去的争点数、段数或目录。请求“结构诊断”时先交诊断；不要未经要求把建议写回正文。

完整书状中的各部分服从当届格式；需要这些部分时，保持其功能不同：事实陈述以可定位记录组织与争点有关的叙事，不隐去决定性不利事实或将推论装成事实；论点概要压缩正文已经成立的理由，不提出新论证；法源表依据实际引证生成，不列整个研究书目；请求事项逐项对应有权限作出的裁判。通常先完成决定性争点，再据完成稿整理引言、概要和请求。

## 思路稿与正文分别表达

用户的写作偏好：在制作思路时提醒本方论证的局限，正式正文集中、有力地推进本方立场，避免花费笔墨作反复的自我限定。这一要求同样适用于工作稿中的拟提交正文和写作指南里的示范正文。

- **思路说明、研究底稿、审校意见**：可以明确写某一来源只能证明哪一环、哪些结论不能由此推出、还缺什么材料及如何补足，供用户作写作取舍。
- **正文**：直接提出本方命题，写出支持该命题的规则、事实与推论；下一要件在相应段落独立完成，不用先声明上一段“不能证明”它。无需逐条声明本方援引的每份法源不能承担哪些其他证明。
- 清理针对本方的“但这不能证明……”“这一点本身不足以……”“仍需另行证明……”等研究提醒；把可完成的证明实际写出来。规则适用条件、决定性例外和为回应具体争点所必需的简短区分保留在对应推理中，不扩成自我反驳段。
- 如本方命题确无材料支撑，先补检、改用可支持的命题或删除无据断言；无法解决的在正文外简短告知用户，不靠增加自我限定句掩盖缺口，也不改成无据的确定结论。用户只要正文时不附常规局限清单。
- 辩方或其他角色指出**对方**未完成证明，是本方实质论证，可以直接写；不要将本偏好误解为禁用一切“不足以证明”表述。

例如，正文不必写“该判例支持行为要件，但不能证明被告的主观状态，后者仍需其他证据”。在其支持的行为要件处完成援引，再到主观要件段用相关记录直接论证被告的认识；前述提醒只留在思路说明中。

## 把 IRAC 写成真正的推理

一个 IRAC 单元可跨几个自然段，篇幅依复杂度调整。

- **I**：提出可裁判的问题或清楚的本方命题，标明所对应的法律条件。标题优先表达结论，但不夸大材料的证明力。
- **R**：给出准确标准、必要条件、相关例外及其来源。先规范、再必要解释；避免判例名单代替规则。直接裁判理由与辅助材料分清。
- **A**：将每个必要条件与具体记录连接，说明为什么这些事实达到或未达到条件，处理最强替代解释。事实复述后接“因此”不足以构成适用。
- **C**：给出与本单元、程序门槛相称的结论，说明它如何推进本方请求。不要在结尾突然加入新事实或新标准。

已有 IRAC 单元内的补充应落入其相应位置。不要为了说明“本节证明功能”另插一个破坏正文流向的元说明板块。用户要求大白话讲解时，可在写作指南或单独解释中讲清作用；不要自动混入正式书状。

## 反论嵌入与主备位

先以本方标准和事实提出成立理由，再在相关规则或适用处处理具体反论。最有力的回应通常是指出对方错用了哪一条件、事实性质、时间或法源范围，然后补足本方的正面证明。

实际对手书状可按页段引用；赛题列明的动议依赛题定位。自行预判写为可能反论，不声称对手确实说过。旧赛季或其他场次的书状/庭审只能用于启发或对照，不成为新案件事实和对方立场来源。

明确主位与备位的前提。备位须在明确的假定前提下，以独立理由支持本方结论或次位救济；可以支持同一最终请求，但不能只是换一种说法重复主位理由。不要用“即使基础犯罪成立”掩盖尚未证明的个人责任。

## 可读性与篇幅

- 每段围绕一个主要法律动作推进：提出标准、解释限定、完成事实适用或回答反论。一个句子中嵌套多个前提时拆开，保留推理连接。
- 用精确行为人、对象、时间和条件替代“具体情境”“制度本质”“当然”等无法检验的概括。
- 正文留下裁判所需理由；原文长摘、研究轨迹和备选资料放工作底稿，除非用户需要参考汇编。
- 压缩先删重复、空泛导语、针对本方的研究性自我限定和不服务当前争点的旁支，保留法律规则的必要条件、主观要件、证明桥梁和核心定位。
- 英文正文保持法律术语一致。中英文对照应核实同一法律命题，不追求字面整齐而改变范围、否定或主语。

中文书状的争点表达、事实陈述、论点总结、正文论证、法律意见和完整排版要求，按 [中文书状的规则、版式与语言](chinese-memorial-format-and-language.md) 核对。英文书状的结论型标题、段落节奏、正式语域和完整排版要求，另见 [英文书状的规则、版式与语言](format-and-language.md)。两份参考都区分当届硬规则、获奖样本和可选编辑建议，起草时不要跨语言混用。

篇幅报告使用实际规则：是否计脚注、标题、目录和文献表，中文计字或英文计词。没有规则只报告采用的计数方式及实际结果，不宣称已通过竞赛限额检查。

## 修改现稿

先确认目标文件和版本，读取前后段落及牵连脚注。用户已选定分支时沿该分支修改；不把不同版本拼成“更完整”但未经选择的稿件。

进行局部编辑时：

1. 保留改前副本或可审阅差异，选择与影响相称的方法。
2. 保持用户要求不动的文字、来源和格式；只调整使本次修改成立的依赖项。
3. 新增事实回到记录，新增规则回到来源；语言润色不抬高确定性。
4. 核查修改范围外是否被工具连带改动，并如实说明不可避免的变化。
5. 修改完成后，按 `icc-moot-footnote-verifier` 复核受影响脚注；完整交付稿执行 `full`，局部修改至少复核被改段落所涉脚注及其回指。

DOCX 的“只改某段/脚注”需用适合范围的工具，必要时比较包内 XML、脚注锚点和受保护正文；不要为了一个小修改重建整篇导致样式、目录、书签或脚注丢失。仅格式处理不得顺手进行实体改写。
