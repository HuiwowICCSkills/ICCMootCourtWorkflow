# 法源与引证

## 先识别适用路径，再评价权重

以《罗马规约》第21条的适用法结构为起点，结合第9条、第51条及第21(3)条等相关要求核对具体规范的地位与一致性。不要把所有材料排成一个脱离问题的机械等级表。

- 《规约》《犯罪要件》《程序与证据规则》各有职能及一致性限制；不能从要件文本反推一个与《规约》冲突的新罪名。
- ICC 先前决定应核对分庭、程序、裁判问题和后续处理。依第21(2)条说明先前解释的作用，不简单断言所有先例具有普遍拘束力，也不因缺少一般先例拘束制度就忽略上诉分庭解释、发回指示或本程序内裁判效力。
- 其他国际法庭及国内法院判例用于解释或类比时，说明规范文字、制度背景与事实相似性；不同法院的定义不能无论证地移植。
- 条约适用、习惯国际法及一般法律原则各有成立路径。援引某条约、宣言、手册或决议，不自动证明其全部内容为习惯法。主张习惯须说明相关实践与法律确信；若依某法院既有认定论证，准确归属于该法院并保留其范围。
- 手册、决议和研究报告须按其性质使用；学术评注可用于理解、发现争点及回溯一手引证。赛规及用户指示未禁止时，可按论证需要引用学术观点，明确其辅助论证身份，不包装成法院裁判或独立约束规则；有明确的来源使用限制时依该限制处理。

罪名解释注意第22条严格解释与禁止不利类推的限制；不要把跨制度类比直接当作创设犯罪的根据，也不要把罪刑法定的特定要求机械变成所有程序条款的一般解释规则。

## 最小可复用的来源记录

对准备进入正文的关键命题，保留足以回查的记录。已有表格可复用，不强制迁移到新的格式。

| 字段 | 内容 |
|---|---|
| 身份 | 案名/文书名、法院与分庭、案号/文件号、日期、裁判类型或版本 |
| 定位 | 段号或印刷页码；必要时另列 PDF 文件页序；条文精确到款项 |
| 原文 | 支持该命题的原句及必要上下文；保留否定、条件、例外和引语主体 |
| 命题 | 本稿实际要证明的具体内容；不要只写“支持本方” |
| 作用与限制 | 规则解释、事实类比、反例、救济依据等；适用范围与关键差异 |
| 状态 | 已读原文/仅次级转引/仅元数据或预览/无法取得；已知上诉或后续改变 |
| 获取位置 | 实际本地文件与定位，或可用原文 URL；有版本风险时记录取得日期 |

对旧核验结果，检查当前命题是否仍在原核验范围内。无需因每次改写重复全库核验；也不能以“以前核过案号”代替对新命题的核验。法源截止日明确时只将允许的材料用于提交稿，较晚材料如用于理解须单独处理。

## 读判例时的关键区分

1. 法院的多数理由、个别/反对意见、当事方陈述、法院引用他人的观点，是不同来源。
2. 逮捕令决定、确认指控决定、一审、上诉、复核及赔偿决定，是不同文书；同一案名不能抹平程序和结论的区别。
3. 检索摘要、新闻稿、报告的 headnote 只能表明其实际内容，不能伪装成已读取的判决全文。
4. 抽取一句话前后读够语境，尤其检查“not”“unless”“even if”、对方提出而法院否定的论点以及事实限定。
5. 类比说明共同点、重要差异、可以迁移的规则与不能推定的要件。一个判例支持其中一环，不等于证明完整犯罪或全部个人责任。

## 引文、脚注与双语

- 按当届规则和用户指定体例出具引证，不擅定 OSCOLA、Bluebook、英文脚注或特定缩略格式。
- 当届规则可能进一步规定脚注字号、是否计入词数、统一引证体系、缩略语登记和权威索引对应关系。2027 年 IBA ICCMCC 规则要求全篇只采用一种体系、索引中的来源均进入脚注，并先在索引中说明缩略形式；使用年份快照前仍须回查当届规则。
- 脚注锚点紧邻被支持命题；一条注支持多个命题时检查是否真的覆盖全部内容。共用同一案件不代表可以合并不同段落的引证。
- 不捏造案号、页码、段号、引语或版本。找不到原文就标出缺口；次级转引若在工作稿中使用，明确“转引自”，不声称已直接核验。
- 工作稿和写作指南优先在相关命题旁放可点击原文定位；提交稿的链接与脚注外观服从比赛规则。PDF 页序与印刷页码分别记，不把 `#page=` 的存在说成已验证能准确跳页。
- 引号内忠实原文。译文注明性质；自行译述不是官方译文。脚注表达语言与来源语言分别确定：有适合的控制性英文版本时优先使用；仅有其他语言原件时如实引证并标注语言或译文性质，不将其回译后冒称英文原句。用户要求特定原文版本时依其要求，取得不了则明确说明。
- 语言版本冲突会改变事实、权限或要件时，列出差异并依当届控制性版本/官方澄清处理。未规定优先语言时只对受影响部分保留分支或询问，不默默混合两版最有利的句子。
- `ibid.`、`supra`、交叉引用和短引在重排或删注后重查；文献表列有来源不意味着正文已正确援引。

书状工作流默认在起草、修改和定稿时调用 `icc-moot-footnote-verifier`。本文件“最小可复用的来源记录”中的身份、定位、原文、命题、作用与限制、状态、获取位置，可直接作为 citation ledger 的输入；但写作思路中的引文块仍只是线索，核验必须回到原件。核验后的最小校正范围与禁止事项见该 skill 的 `references/verification-protocol.md`。

## 针对性补检

先写清缺口：“要证明什么，需要哪一类型的一手材料”。用条款、英文概念、确切案号或已知脚注找原文。获取情况分别标记为全文、节选、预览、目录、元数据、受限或未取得；一次搜索无结果不等于不存在。

来源无法取得时，继续完成已有可靠材料支持的部分。若某一不可替代的核心命题仍无支持，在思路或审校记录中标出缺口，并在正文外向用户报告它对结论的影响；正文只提出有材料支持的命题，不逐段加入本方“尚不能证明”的研究提醒，也不得用貌似完整的引证补齐外观。
